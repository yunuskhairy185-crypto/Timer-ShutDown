Auto Shutdown

Auto Shutdown is a free Windows application that lets you set a specific time duration before your computer automatically shuts down.

Features
Set a custom shutdown timer.
Automatically shut down your computer when the timer expires.
Simple and easy to use.
How to Use
Open the application.
Set the desired time duration.
Start the timer.
Your computer will shut down automatically when the time runs out.
